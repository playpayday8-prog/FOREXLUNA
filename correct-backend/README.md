# Forex Luna Signal Backend

Deploy this to Render.com

## Deploy to Render:
1. Connect this repo to Render
2. Select "Web Service"
3. Use default settings
4. Add environment variable: WEBHOOK_SECRET=your-secret-key

## Frontend URL:
https://lunasignals.netlify.app

## After deployment, update frontend to use:
https://forex-luna-backend.onrender.com/api/trade
